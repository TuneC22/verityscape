## Installation tutorial (eng)
To actually play the mod you'll need Fleasion - an application for roblox used to replace images, models, audio etc. It's safe and won't get your account banned, if you're interested you can check Fleasion github page for more info.

1. Download `verityscape.json` (from this repository)
2. Download **Fleasion** from official GitHub repository (https://github.com/fleasion/fleasion)
3. Open **Fleasion**, look in the bottom right corner and press **"Open Configs"** button
4. Place `verityscape.json` in the opened folder
5. Return to **Fleasion**, select **verityscape** in the **"Enabled"** dropdown list (top left corner)
6. Press **"Clear Cache"** in the bottom right corner, you will have to do this __everytime__ you make a change in configuration
7. Congrats, you can now play nullscape with verity!

You can change the state of any of the sprites (will they take effect), for this just press **RMB** on a desired profile and press **Disable Profile**

## Инструкция по установке (rus)
Чтобы играть с модом, вам понадобится Fleasion — приложение для Roblox, которое используется для замены изображений, моделей, аудио и прочего. Оно безопасно и не приведёт к блокировке аккаунта, а если вам интересно, можете посмотреть страницу Fleasion на GitHub для дополнительной информации.

1. Скачайте `verityscape.json` из этого репозитория
2. Скачайте **Fleasion** из официального репозитория на GitHub (https://github.com/fleasion/fleasion)
3. Откройте **Fleasion**, найдите в правом нижнем углу кнопку **"Open Configs"** и нажмите на неё
4. Поместите `verityscape.json` в открывшуюся папку
5. Вернитесь в **Fleasion** и выберите **verityscape** в выпадающем списке **"Enabled"** (в левом верхнем углу)
6. Нажмите **"Clear Cache"** в правом нижнем углу. Вам придётся делать это __каждый раз__, когда вы вносите изменения в конфигурацию
7. Поздравляем, теперь вы можете играть в nullscape с верити!

Вы можете изменить состояние любого спрайта (будет ли он менять оригинальные спрайты или нет). Для этого нажмите **ПКМ** по нужному профилю и выберите **"Disable Profile"**.
